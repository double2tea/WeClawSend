剪辑软件

剪辑软件里直接发送

Premiere Pro、Final Cut Pro 和 DaVinci Resolve 都能接上。

Premiere Pro

导出完成后自动发送

选择完整序列或 I/O 范围，沿用 Adobe 导出预设。发送中可继续下一个序列。

  • 记住预设与输出目录
  • 失败只重试发送，不重新渲染
Final Cut Pro

原生分享动作，无需插件

把 WeClaw Send 设为导出完成动作，分享结束后自动进入发送队列。

  • 不需要开启本地接口
  • 可单独建立“导出并发送微信”目的位置
DaVinci Resolve

在 Deliver 页面直接发送

渲染完成后通过本机接口发送。推荐 Lua 入口，使用 macOS 自带 curl，无需 Python。

  • App 设置中一键安装
  • Resolve 21+ 使用前需关闭后台渲染

常见问题

安装和发送时
最常问的几件事

一定要安装 OpenClaw 吗+

不需要。WeClaw Send 可以直接扫码；已经在用 OpenClaw 时，选择复用就不用再扫码。

为什么扫码后还没显示“已连接”+

扫码确认后，再在微信里给 ClawBot 发任意消息。应用取得可发送文件的会话后，才会显示“已连接”。

复用 OpenClaw 时需要保持它运行吗+

需要。登录和收消息仍由 OpenClaw 管理，WeClaw Send 只读取当前账号和会话来发送文件。

首次打开被 macOS 拦截+

先尝试打开一次，再到“系统设置 → 隐私与安全性”选择“仍要打开”。

文件大小与并发限制+

默认单文件上限 200 MB，可在设置中调到 2 GB；最多同时处理 3 个文件。

文件篮会复制或删除原文件吗+

外部文件只保存路径引用，移除或删除文件篮都不会改动 Finder 里的原文件。粘贴生成的文本便笺和图片便笺由应用托管；删除篮或移除项目、且没有其它引用时，会从本机删除这些便笺。

可以安排稍后发送吗+

可以。先选文件，再点一个预设时间即可加入待发送；自定义分钟后点确定。计划在“等待发送”区显示倒计时，可立即发送、改时间或取消。图片、视频和 PDF 显示内容缩略图，点缩略图或按空格预览。创建计划不要求微信当下在线；到点离线、文件缺失或文件发生变化时会进入“需要注意”，应用退出期间错过时间也不会在重启后静默补发。本地接口同步提供 /scheduled-sends 计划管理；/send 默认直接发送，也可设置为先加入文件篮。

2.3 有哪些改进+

文件篮新增展开阅读和置顶提醒栏：文本可搜索、编辑和勾选待办，PDF 可滚动缩放，图片可适应窗口或按像素显示。也可粘贴文本便笺与图片。2.2 的延时发送、缩略图预览和计划跨重启保存仍然保留。
