WeClaw Send 使用说明

把文件拖到菜单栏纸飞机，直接发送到自己的微信。

macOS 14+Apple 芯片 + Intel无需 Xcode本地接口默认关闭
▶ 观看中文视频教程
首次打开需要手动批准：当前版本没有 Apple Developer ID。请按下方第 2 步，在“系统设置 → 隐私与安全性”中点“仍要打开”。不要执行来源不明的终端命令。

三步开始使用

1

打开并安装

打开 DMG 或解压 ZIP，把 WeClaw Send 拖入“应用程序”。

2

批准首次打开

先打开一次，再到“系统设置 → 隐私与安全性”，点“仍要打开”。

3

登录并发送

独立扫码或只读复用 OpenClaw 登录，然后拖入文件即可发送。

详细步骤

安装与首次打开

  1. 打开 DMG，或解压 ZIP。
  2. 把 App 拖入“应用程序”。
  3. 打开一次，看到拦截提示后关闭提示框。
  4. 打开“系统设置 → 隐私与安全性”。
  5. 找到 WeClaw Send，点“仍要打开”，再确认“打开”。

微信登录

  1. 点击菜单栏纸飞机。
  2. 独立使用时，在设置中点“扫码登录”，用手机微信扫码并确认。
  3. 若手机显示配对码，按提示输入。
  4. 已经使用 OpenClaw 时，可把登录方式切到 OpenClaw；单账号自动选中，多账号需要手动选择。
  5. 看到“已登录”后返回发送页。

OpenClaw 模式只读使用其当前账号和会话，不复制或修改 OpenClaw 文件，也不收取微信消息。发送和等待会话刷新时请保持 OpenClaw 运行。

发送文件与文件篮

  • 把文件直接拖到菜单栏纸飞机会立即发送。
  • 或打开面板，拖到发送区域，也可以点击“选择文件”。
  • 短暂网络中断、超时或服务端临时错误会自动重试最多 3 次；CDN 上传会从头重新上传同一加密文件，并非断点续传。发送任务列表里，图片、视频和 PDF 显示内容缩略图，其它文件用类型图标；点缩略图或选中后按空格可预览，连按文件名在 Finder 中显示。右键菜单栏纸飞机可打开、进入设置或退出。
  • 需要稍后再发时，点主面板任务列表旁的时钟按钮选择文件，再点一个预设时间即可加入待发送；自定义分钟后点“确定”。计划会出现在“等待发送”区，显示倒计时，并支持立即发送、改时间或取消。也可在设置里把默认发送方式改成“每次询问”或“固定延时”。
  • 创建延时计划不要求微信当前在线，计划会保存在本机。到点若微信离线、文件缺失或发生变化，会进入“需要注意”；应用退出期间错过时间，重启后也不会静默补发。
  • 点主面板文件篮按钮显示或隐藏最近使用的篮，菜单可新建；按 ⌥⌘S 显示或隐藏最近使用的文件篮；拖着文件左右摇晃会在指针旁展开文件篮，松手时未放入文件则自动收起。
  • 可同时打开多个独立文件篮，每个篮保存自己的文件、位置、折叠与置顶状态；主面板可显示全部、关闭全部、删除指定篮或确认后删除全部文件篮。
  • 文件篮默认显示三列缩略图网格，标题栏可切换网格或列表；图片、视频与文档会尽量显示 Quick Look 缩略图，其它项目显示系统文件图标。
  • 文件篮顶部“…”菜单或文件项目右键菜单均可通过隔空投送、邮件和信息分享当前多选集合。
  • 单选后可点“展开阅读”或按 ⌘Return：文本可搜索编辑，PDF 可滚动缩放，图片可按像素显示，视频和音频可看波形、拖进度并倍速播放。文本可钉成提醒栏并勾选 - [ ] 待办。
  • 外部文件只保存路径引用，不复制或移动原内容；也可粘贴文本便笺和图片。从网格或列表空白处拖框，或按 ⌘A、⌘ 点选、Shift 点选可多选，再批量拖出、复制或移除。
  • 普通文件可立即发送或加入延时计划；文件夹与 macOS 包会先按名称压缩成单个 ZIP，再发送或加入计划。创建计划后文件篮仍保留原项目。
  • 窗口“…”菜单可先输入压缩包名称，再把当前篮压缩成单个 ZIP 并立即发送；也可复制全部文件路径或在 Finder 中显示全部文件；ZIP 发送不会清空当前篮。
  • 关闭空文件篮会自动删除；窗口“…”菜单可清空或删除当前篮。删除篮不会改动 Finder 里的原文件，但会删除未再被引用的文本便笺和图片便笺。
  • 不支持符号链接或后台剪贴板历史；相关新建、保留、恢复和发送后清空行为可在设置中调整。
  • 最近传输会显示准备、加密、上传和完成状态。

设置与限制

  • 单文件上限默认 200 MB，可在设置中选择 100 MB、200 MB、500 MB、1 GB 或 2 GB；较大文件仍可能被微信服务拒绝。可开启“发送结果通知”，多文件结果合并为一条系统通知。
  • 最多同时处理 3 个文件；加密和 CDN 上传可并行，微信消息提交保持串行且间隔约 2 秒。
  • 会话受限时 App 会提示你给 ClawBot 发一条消息，收到后自动重试原文件；会话刷新提醒会在恢复或结束后自动撤销，系统通知权限关闭时不会弹出阻塞提示。
  • 本地接口默认关闭；仅脚本自动化、Premiere 和 DaVinci 自动发送需要开启，Final Cut Pro 不需要。
  • 独立登录的信息保存在当前用户的 Application Support，文件权限为 0600；OpenClaw 模式不复制其登录文件。

在线更新与编辑器安装

  • 设置中的“检查并更新”优先从 GitHub Release 获取版本与 App ZIP，不可达时自动回退到官网 Cloudflare CDN；下载后仍会校验 SHA-256，再在退出后替换和重启。
  • App 会识别、修复、更新或卸载本地 Premiere 插件 / DaVinci 脚本，并防止线上旧版覆盖本地新版。DaVinci 默认推荐 WeClawSend_Lua（无需 Python）；完整步骤见下方“DaVinci Resolve（可选）”。设置页另有“发送结果通知”，多文件结果会合并为一条系统通知。
  • App 更新要求所在目录可写；提示不可写时，请移至当前用户的“应用程序”目录。
  • 安装编辑器集成后，重启对应编辑器。
  • 设置页可直接打开 官方网站，底部还可打开 GitHub、个人作品集 或发送邮件。

Premiere Pro 25+（可选）

  1. 在 App“设置 → 更新与编辑器集成”中点击 Premiere Pro 插件的安装、修复或更新按钮。
  2. 重新打开 Premiere，在“窗口 → 扩展 → WeClaw Send”打开面板。
  3. 从下拉框选择自动扫描到的用户或系统预设。
  4. 选择“完整序列”或“入点到出点（I/O）”；I/O 未设置或范围无效时面板会提示。
  5. 需要导出后自动发送时，先在 App 设置中开启“本地接口”。

面板保持稳定的单序列导出路径，会扫描所有已安装的 Premiere 与 Adobe Media Encoder 25+ 预设并记住上次选择。重新获得焦点时会同步当前序列名，手动文件名不会被覆盖；同名输出会阻止覆盖，完成后可在 Finder 中显示。开启自动发送后，面板会先检查本机接口，渲染完成即允许继续操作并在后台发送；一个或多个发送失败时可逐个仅重试发送，不会重复渲染。修改参数时，在 Premiere 原生导出页保存预设，再回面板刷新。项目只维护 CEP 12 版本，自动发送默认关闭。

Final Cut Pro（可选）

  1. 安装 WeClaw Send 1.6.8 或更高版本，打开并确认微信已登录。
  2. 打开“Final Cut Pro → 设置 → 目的位置（Destinations）”。
  3. 选择“导出文件（Export File）”，把“操作（Action）”设为“其他（Other）”。
  4. 选择 /Applications/WeClaw Send.app，返回后确认“操作”显示 WeClaw Send。
  5. 使用这个目的位置分享；Final Cut Pro 提示成功后，WeClaw Send 会弹出并开始发送。

此方式使用 Final Cut Pro 的原生分享完成动作，不需要插件，也不需要开启本地接口。建议选择 H.264 或 HEVC，把单个成片控制在 200 MB 以内。若分享成功但没有新增传输记录，请确认版本不低于 1.6.8，并在“操作 → 其他”中重新选择上述 App，避免仍指向旧版本或另一份 App。

DaVinci Resolve（可选）

  1. 推荐使用 WeClawSend_Lua（无需 Python，依赖 macOS curl）。可选入口 WeClawSend_Python 仅在你需要 Python 宿主脚本时使用。
  2. 在 App“设置 → 更新与编辑器集成”中点击 DaVinci Resolve 脚本的安装 / 修复 / 更新；不需要时可卸载。新版安装会自动清理旧的 自动发送ClawBot_* 等入口。Premiere 插件同样支持卸载。
  3. 安装成功后，设置页会显示安装路径；可点“显示路径”确认 WeClawSend_Lua.lua（及可选的 WeClawSend_Python.py）。
  4. 在 App 设置中开启“本地接口”。
  5. 完全退出并重新打开 DaVinci Resolve（脚本只在启动时扫描）。
  6. 在 Deliver 页“在渲染作业结束时触发脚本”中优先选择 WeClawSend_Lua。MP4/M4V 显示名由设置“发送时 .mp4 显示为 .m4v”处理，脚本不再分模式。

脚本会安装到用户 Deliver 目录；系统目录可写时也会同步。不会修改项目文件或导出预设。若下拉只有“无”，确认已安装 WeClawSend_Lua.lua 并已彻底重启 Resolve。

常见问题

打开后没有窗口

这是菜单栏应用，不会固定显示在 Dock。请查看屏幕右上角 Wi‑Fi、电池附近的纸飞机图标。

提示 App 已损坏

删除当前 App，重新打开原始 DMG 或解压原始 ZIP，然后拖入“应用程序”并按首次打开步骤批准。不要使用来源不明的终端命令。

扫码确认后一直等待

先在微信里给 ClawBot 发一条任意消息；微信通常会随即完成登录确认。若仍未完成，请取消后重新扫码，并暂时关闭 VPN、代理或网络过滤工具。App 最多等待 5 分钟，不会无限转圈。

发送失败

确认设置页显示微信已登录、网络可访问微信服务、文件没有超过设置中的单文件上限。使用 OpenClaw 登录时还要确认 OpenClaw 正在运行。若 App 提示刷新会话，请给 ClawBot 发任意消息，App 收到后会自动重试；独立登录必要时可重新扫码。

脚本连接被拒绝

本地接口默认关闭。需要自动化时，在设置中打开“启用本地接口”，地址为 127.0.0.1:18790。
