## 已确认的升级策略

2.5.3 更新器不检查目标系统要求，不能直接向它提供 macOS 26+ 的同名更新包。

用户已选择保留 macOS 26 门槛，改用 `WeClaw-Send-macOS26.zip`。客户端常量、打包脚本、GitHub Release 附件、网站重定向与下载函数已同步。新版 Release 不得附带 `WeClaw-Send.zip`，网站也不得把新版包映射回这个旧名称。

2.5.x 内置更新会因找不到旧名称附件而停止，不替换原应用。macOS 26+ 用户手动下载安装一次；macOS 14/15 用户继续使用 2.5.3。新客户端后续使用新名称自动更新。

网站部署根据线上 Release 选择附件；在 2.6.0 发布前允许把实际的 2.5.x 包复制到新网站下载路径。该复制只允许旧包到新路径，禁止反向别名。部署前仍按原始附件名称验证 SHA-256。
